# Antviz — статический сайт

Без бэкенда и сборки: откройте `index.html` в браузере или выложите папку на любой хостинг.

```
antviz/
├── index.html                    главная (герой, студия, услуги, процесс, кейсы, контакты)
├── 404.html
├── uslugi/
│   ├── index.html                все услуги
│   ├── razrabotka-sajtov/
│   ├── razrabotka-prilozhenij/
│   ├── telegram-boty/
│   ├── vnedrenie-ii/
│   ├── vnedrenie-crm/
│   └── seo-prodvizhenie/
├── kejsy/
│   ├── index.html                все кейсы
│   ├── sajt-dlya-kofejni/
│   ├── internet-magazin/
│   ├── bot-zapisi/
│   └── crm-uchet/
├── kontakty/index.html           контакты и форма-конструктор сообщения в Telegram
├── demo/                         живые демо для кейсов
├── screenshots/                  скриншоты демо (открываются на страницах кейсов)
└── assets/
    ├── css/style.css             единый файл стилей
    ├── js/main.js                единый файл скриптов
    ├── fonts/                    Unbounded, Golos Text (woff2)
    └── img/favicon.svg
```
